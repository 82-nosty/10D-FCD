# 10D-FCD 통합 패치 내역 및 릴리즈 노트

**버전**: v2.2.0 (Enterprise & Multi-Location Update)  
**대상 하드웨어**: ESP32-2432S028 (CYD 2.8" ILI9341, Dual-Core 240MHz)  

---

## 1. 패치 개요 및 요약

| 구분 | 이전 버전 (기존) | 개선 버전 (패치 후) |
| :--- | :--- | :--- |
| **와이파이 인증 방식** | 단순 WPA2-PSK (비밀번호만) 지원 | **WPA2/WPA3-Enterprise (802.1X EAP-PEAP)** 지원 (ID + PW + 인증서 옵션) |
| **엔터프라이즈망 입력 UI** | SSID / PW 2개 입력창만 존재 | 동일 연결 버튼 클릭 시 **엔터프라이즈망 감지 시 모달 팝업** 표출 |
| **시간 동기화 (NTP)** | 외부 UDP 123 (`pool.ntp.org`)에만 의존 (방화벽 차단망 시계 정지) | **PC 시스템 시간 직접 주입 (`SET_TIME` & TCP `TIME:`)** + 국내 NTP 3중 폴백 |
| **무선 스트리밍 안정성** | 파이프라이닝 전송 (지연 시 버퍼 오버플로우로 연결 끊김) | **1:1 Strict Lock-step ACK (`'K'`)** + 소켓 64KB 버퍼 + 3.0초 타임아웃 |
| **장소 이동 편의성** | 최근 연결된 단 1개 AP만 덮어쓰기 저장 | **최대 10개 AP NVS 영구 보존**, 부팅 시 **주변 자동 스캔 매칭** 접속 |
| **저장 프로필 관리** | 기기 내부 확인/삭제 불가 (초기화 불가) | PC [시스템 설정] 탭에서 **목록 조회 및 선택 삭제** 지원 |

## 2. 주요 개선 사항 및 기술적 해결 방법

### 1) 와이파이 지원 범위 확장 (802.1X EAP Enterprise)
* **목적 및 배경**:
  * 기업, 공공기관 및 대규모 엔터프라이즈 환경에서 사용하는 WPA Enterprise 인증 방식을 지원하여 기기 활용 범위를 대폭 확장.
  * 기존 단순 패스워드 방식 외에 **사용자 ID(계정명)** 및 **CA 인증서** 기반 인증 지원.
* **구현 내용**:
  * **ESP32 Wi-Fi 스캔 태깅**: Wi-Fi 스캔 시 `WiFi.encryptionType(i)`가 `WIFI_AUTH_WPA2_ENTERPRISE` 또는 `WIFI_AUTH_WPA3_ENTERPRISE`인 경우 SSID 뒤에 식별 태그(`#EAP`)를 부착하여 PC로 전달.
  * **엔터프라이즈 설정 모달**:
    * 사용자가 `[공유기 연결]` 버튼 클릭 시 엔터프라이즈망을 감지하면 자동으로 ID 및 인증서 설정 모달 실행.
    * 사용자 ID 입력 및 "인증서 검증 안 함"(일반적인 사내망 권장) 또는 인증서 파일(.pem, .crt) 선택 지원.
  * **ESP32 펌웨어 구현**:
    * `esp_eap_client.h`, `esp_wifi.h`를 활성화하여 `esp_eap_client_set_identity()`, `esp_eap_client_set_username()`, `esp_eap_client_set_password()` 및 `esp_wifi_sta_enterprise_enable()` 적용.

### 2) 외부 NTP 차단망 대응 시간 동기화 보강
* **목적 및 배경**:
  * 보안 정책상 외부 UDP 123(NTP) 포트가 차단된 폐쇄망/보안망 환경에서도 기기 화면의 시계가 항상 정확하게 표시되도록 개선.
* **구현 내용**:
  * **PC RTC 주입 프로토콜 (`SET_TIME:<epoch>`)**:
    * USB 시리얼 포트 연결 및 무선 TCP 스트리밍 세션 시작 시 PC의 현재 시스템 시각(Unix Timestamp)을 기기에 즉시 주입.
    * ESP32는 `settimeofday(&tv, NULL)`을 호출하여 하드웨어 RTC를 보정하므로 외부 인터넷망의 NTP 차단 여부와 무관하게 정확한 시간 유지.
  * 외부 NTP 서버 리스트를 국내망 접속율이 높은 `time.bora.net`, `kr.pool.ntp.org`, `pool.ntp.org` 3중 구조로 재배치.

### 3) 무선 스트리밍 안정성 및 지연 대응 강화
* **목적 및 배경**:
  * 대역폭 제어나 패킷 지연(Jitter)이 발생하는 네트워크 환경에서 프레임 누적으로 인한 소켓 끊김 방지.
* **구현 내용**:
  * **Strict 1:1 Lock-step ACK**:
    * PC는 1프레임을 보낸 후 기기가 디코딩 및 수신 준비를 마치고 반환하는 ACK(`'K'`)를 확인한 뒤에만 다음 프레임을 송신하도록 완벽 동기화.
  * **소켓 버퍼 및 타임아웃 확장**:
    * PC 송수신 버퍼를 64KB(`SO_SNDBUF`, `SO_RCVBUF`)로 확장하고 연결 타임아웃을 6.0초로 연장.
    * ESP32 펌웨어 내 수신 루프 타임아웃을 기존 1.5초에서 3.0초로 늘려 순간적인 지연 발생 시에도 연결 유지.

### 4) 다중 장소 이동 환경을 위한 스마트 Wi-Fi 프로필 시스템
* **목적 및 배경**:
  * 집, 사무실 등 장소를 옮겨 다닐 때마다 매번 Wi-Fi 설정을 새로 입력해야 하는 번거로움 해소.
* **구현 내용**:
  * **최대 10개 프로필 NVS 영구 저장 구조체**:
    * `w_0_~`, `w_9_~` 네임스페이스를 통해 일반 공유기 및 "인증서 검증 안 함"으로 연결된 엔터프라이즈망을 ESP32 플래시 메모리에 유지.
  * **부팅 시 자동 스캔 매칭 (`checkWifiAndInit`)**:
    * 기기 부팅 시 주변 AP를 스캔하고, **저장된 목록 중 주변에 켜져 있는 AP를 우선 찾아 자동으로 접속**.
  * **프로그램 설정 내 GUI 관리 기능**:
    * PC 클라이언트 설정 탭에 `기기 저장 Wi-Fi 네트워크 관리` 기능 추가.
    * `GET_WIFI_PROFILES`로 기기에 저장된 SSID 목록 조회 및 `DEL_WIFI_PROFILE:<SSID>`로 선택 삭제 지원.
